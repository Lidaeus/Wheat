# 作物模型参数率定规范与文献综述

## 1. 综述背景
在 DSSAT、APSIM 等基于过程的作物模型率定中，核心挑战在于如何平衡**异源（Heterogeneous）**、**异量纲（Different Scales）**且**采样频率不一**的观测数据。例如，产量（Yield, ~10³ kg/ha）与叶面积指数（LAI, ~10⁰）在数值上相差 1000 倍，且产量通常只有 1 个采样点，而 LAI 有多个动态采样点。

## 2. 基础权重处理（Weighting Strategies）

### 2.1 统计学原则：倒数方差法（Inverse Variance）
*   **经典理论**：PEST 创始人 John Doherty 提出，权重 $w_i$ 应与观测误差的标准差 $\sigma_i$ 成反比：
    $$w_i = \frac{1}{\sigma_i}$$
*   **科学依据**：这使得加权残差平方和 $\Phi$ 具有最大似然估计（Maximum Likelihood Estimation, MLE）的含义。如果观测仪器精度高（$\sigma$ 小），则权重应大。
*   **局限性**：在作物模型中，由于存在严重的**结构性误差**（Model Structural Noise），纯统计学权重往往失效，导致数值大的指标（如产量）完全霸凌数值小的指标。

### 2.2 工程实践原则：贡献对等法（Equal Contribution）
*   **做法**：通过调整权重，使得在优化开始时，每个**观测组（Observation Group）**对总损失函数 $\Phi$ 的贡献大致相等。
*   **工具支持**：PEST 官方提供了 `PWTADJ1` 等工具来自动实现这一平衡。
*   **结论**：这是目前科研中最通用的做法，旨在防止优化器产生“忽视弱势指标”的偏见。

## 3. 归一化与尺度对齐（Normalization & Scaling）

### 3.1 Z-Score 归一化（Z-Score Normalization）
*   **适用场景**：MGDA 等深度学习背景的算法。
*   **操作**：将所有观测值转化为均值为 0、方差为 1 的分布。
*   **优势**：彻底消除物理单位影响，使梯度在几何上具有可比性。

### 3.2 均值归一化（Mean Normalization / NRMSE 逻辑）
*   **做法**：将残差除以该组观测值的均值 $\bar{Obs}$。
*   **公式**：$r_{norm} = \frac{Obs - Sim}{\bar{Obs}}$。
*   **评价**：这是农学论文中最常见的评价口径（对应 NRMSE），但在优化过程中作为 Loss 使用时，如果均值接近 0（如早期 LAI），会导致数值不稳定。

## 4. 观测指标分组（Observation Grouping）

在所有前沿研究（如 AgMIP 协议）中，**分组是必须执行的步骤**。典型分组方式如下：

| 分组名称 | 包含指标 | 采样频率特征 | 核心权重考量 |
| :--- | :--- | :--- | :--- |
| **产量组 (Yield)** | HWAM, GWAM | 极低（1点/TRT） | 战略地位最高，需手动调大单点权重 |
| **物候组 (Phenology)** | ADAT, MDAT | 极低（1-2点/TRT） | 决定生长期跨度，是其他过程的基础 |
| **动态生长组 (Dynamics)** | LAIX, CWAM | 中/高（序列点） | 点数多，需防止通过点数优势主导优化 |
| **环境组 (State)** | SWAD, NIAD | 高（传感器序列） | 噪声大，自相关强，通常给予较低权重 |

## 5. 前沿算法行为对比

| 特性 | 传统 PEST-GLM | 多目标进化算法 (NSGA-II) | PEST+MGDA (本项目) |
| :--- | :--- | :--- | :--- |
| **权重依赖** | 高（需预设静态权重） | 无（依靠非支配排序） | **自动（动态计算 α）** |
| **收敛速度** | 快（局部梯度） | 慢（全局随机） | **快（雅可比引导）** |
| **多目标处理** | 标量化（求和） | 寻找帕累托前沿 | **寻找公共下降方向** |

## 6. 结论与本项目建议

1.  **分组是红线**：绝不能将产量和 LAI 混在一个组里。
2.  **权重对齐**：为了让 PEST-GLM 与 MGDA 具有公平的竞赛环境，PEST 的权重必须反映组间的平衡（即使用 $1/(\sigma \sqrt{N})$），而不是默认的 1.0。
3.  **隔离必要性**：
    *   **Path A (Pure PEST)**：应使用静态的、基于 $1/\sigma$ 的权重分组方案。
    *   **Path B (MGDA)**：在 Path A 的基础上，引入动态的 Alpha 反馈，以解决梯度方向的冲突。
