# 主脚本执行流程拆解

## 1. 先给出总流程

[DSSAT_PEST.r](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L2-L603) 可以拆成 5 个阶段：

1. 读取输入配置
2. 随机生成候选品种参数并用 DSSAT 粗筛
3. 生成 PEST 所需文件
4. 修改 `nash.pst` 并设置权重
5. 用多个较优初值反复运行 PEST，输出最佳结果

## 2. 阶段一：读取配置与初始化

### 2.1 建立工作路径

代码位置：

- [DSSAT_PEST.r:L2-L6](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L2-L6)

这里做了三件事：

- 清空 R 环境
- 记录开始时间
- 用 `getwd()` 作为项目根目录

这意味着脚本严重依赖“当前工作目录正确”这一前提。

### 2.2 读取 3 个 CSV

代码位置：

- [DSSAT_PEST.r:L9-L53](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L9-L53)

这一段把外部配置全部展开成内部变量，例如：

- `DSSAT_path`
- `Ratio`
- `Random_No`
- `CV`
- `Crop_types`
- `GenotypeFilename`
- `CultivarName`
- `CULParameterNo`

### 2.3 准备 DSSAT 工作目录

代码位置：

- [DSSAT_PEST.r:L55-L64](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L55-L64)

脚本会把 DSSAT 安装目录里的 `DSSBatch.v46` 复制到项目的 [DSSAT_Files](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_Files) 中，作为后续模拟运行的本地副本。

## 3. 阶段二：从 CUL 读取目标品种并做随机粗筛

## 3.1 读取目标 `.CUL`

代码位置：

- [DSSAT_PEST.r:L69-L90](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L69-L90)

这里的逻辑是：

- 根据 `GenotypeFilename` 拼出 DSSAT 的 `.CUL` 文件路径
- 用 `CultivarName` 在 `.CUL` 中搜索目标品种行
- 截取品种名与参数段
- 从固定字符区间中解析初始遗传参数

这是脚本中最典型的“固定宽度文本处理”代码。

### 3.2 生成随机参数

代码位置：

- [DSSAT_PEST.r:L93-L123](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L93-L123)

关键机制：

- 在每个参数的最小值与最大值之间做均匀随机采样
- 把原始 cultivar 参数也作为一个候选解放进集合
- 对 `Flag=0` 的参数不做优化，直接回填原值

### 3.3 构造随机试跑批处理

代码位置：

- [DSSAT_PEST.r:L124-L136](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L124-L136)

脚本生成 [CUL_random.bat](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_Files/CUL_random.bat)，其作用是：

- 切盘到当前工作盘
- 进入 `DSSAT_Files`
- 调用 DSSAT 模型可执行文件

### 3.4 逐个候选值运行 DSSAT

代码位置：

- [DSSAT_PEST.r:L157-L193](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L157-L193)

每一轮循环做的是：

1. 用候选参数替换 `.CUL` 中目标行
2. 运行 DSSAT
3. 读取 [Evaluate.OUT](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_Files/Evaluate.OUT)
4. 删除未启用输出和 `-99` 缺失项
5. 计算该候选参数的 fitness

### 3.5 适应度函数是什么

代码核心在：

- [DSSAT_PEST.r:L189-L192](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L189-L192)

公式可以理解为：

`fitness = 所有输出指标匹配度的连乘`

其中单个指标匹配度近似是一个以观测值为尺度、受 `CV` 控制的高斯型相似度：

`exp(-(sim - obs)^2 / (2 * (CV * obs)^2))`

然后再按输出权重指数放大或缩小影响。

### 3.6 保留较优初值

代码位置：

- [DSSAT_PEST.r:L196-L210](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L196-L210)

脚本按 fitness 降序排序，只保留前 `Ratio` 比例的候选，作为后续 PEST 精调的初始解。

这一步非常关键，因为它让 PEST 不必从特别差的起点开始。

## 4. 阶段三：生成 PEST 所需文件

## 4.1 生成 tpl

代码位置：

- [DSSAT_PEST.r:L215-L227](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L215-L227)

逻辑：

- 把待优化参数替换成 PEST 标记，例如 `^MP1^`
- 形成 `.tpl` 文件

样例见 [MZCER046.tpl](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_Files/MZCER046.tpl#L46-L60)。

## 4.2 生成 par

代码位置：

- [DSSAT_PEST.r:L245-L258](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L245-L258)

脚本读取 `.pmt` 参数名列表，再把当前参数初值写成 `.par` 文件，供 PEST 使用。

## 4.3 生成 ins

代码位置：

- [DSSAT_PEST.r:L260-L331](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L260-L331)

这是整个项目最难读的一段之一。

它做的是：

- 从 `Evaluate.OUT` 的表头和数据体推算各输出变量的字符位置
- 过滤掉未启用指标和 `-99`
- 把这些位置写成 [Evaluate.ins](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_Files/Evaluate.ins#L1-L4) 与 [Measure.ins](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_Files/Measure.ins#L1-L4)

你可以把 `ins` 理解为“告诉 PEST 去输出文件的第几列第几字符取值”。

## 4.4 生成初始 pst

代码位置：

- [DSSAT_PEST.r:L333-L358](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L333-L358)

流程是：

- 先用 `inschek` 检查 `ins`
- 再调用 `pestgen`，把 `.par` 与观测数据合成 `nash.pst`

## 5. 阶段四：修改 nash.pst

## 5.1 修改 PEST 控制参数

代码位置：

- [DSSAT_PEST.r:L360-L373](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L360-L373)

主要修改：

- `LAMBDA FACTOR`
- 迭代次数

其输入值来自 [SimulationControl.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/SimulationControl.csv#L1-L7)。

## 5.2 修改参数上下界

代码位置：

- [DSSAT_PEST.r:L374-L403](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L374-L403)

脚本会把 [ParameterOutput.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/ParameterOutput.csv) 中定义的最小值和最大值写入 `nash.pst` 的 `* parameter data` 区。

## 5.3 修改模型命令与输入输出映射

代码位置：

- [DSSAT_PEST.r:L408-L425](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L408-L425)

这一步把 `nash.pst` 和：

- `nash.bat`
- `*.tpl -> *.CUL`
- `*.ins -> Evaluate.OUT`

串起来，形成可执行控制链。

## 5.4 按输出组自动计算权重

代码位置：

- [DSSAT_PEST.r:L427-L456](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L427-L456)

脚本会读取输出分组标识，再以每组观测值最大值的倒数作为权重。

这相当于在做一种“按量纲规模做归一化”的处理，避免大数值变量完全主导目标函数。

## 6. 阶段五：多初值运行 PEST

### 6.1 循环替换参数初值

代码位置：

- [DSSAT_PEST.r:L494-L507](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L494-L507)

对每一个保留下来的候选初值，脚本都会：

- 修改 `nash.pst` 中参数初值字段
- 重新写回 `nash.pst`

### 6.2 运行检查与正式估计

代码位置：

- [DSSAT_PEST.r:L509-L515](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L509-L515)

先执行 `pestchek`，再执行 `pest`。

这说明每个初值都会对应一次完整的 PEST 估计流程。

### 6.3 重新计算 fitness 并提取估计值

代码位置：

- [DSSAT_PEST.r:L518-L569](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L518-L569)

PEST 运行后，脚本再次读取 `Evaluate.OUT` 计算 fitness，并从 `nash.rec` 中提取估计得到的参数值。

### 6.4 汇总最终结果

代码位置：

- [DSSAT_PEST.r:L572-L603](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L572-L603)

最终产物写入 [Cultivar Coefficients.txt](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/Cultivar%20Coefficients.txt#L1-L7)，包括：

- 各个候选校准结果及其 fitness
- 最佳品种参数

## 7. 这个脚本真正的本质

从工程角度看，这个脚本其实不是“算法实现脚本”，而是一个：

- 文本解析器
- 固定宽度文本改写器
- 外部程序调度器
- 结果收集器

它把原本手工完成的 DSSAT + PEST 标定流程，串成了一条可以自动循环执行的流水线。
