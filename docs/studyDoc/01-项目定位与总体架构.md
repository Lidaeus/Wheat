# 项目定位与总体架构

## 1. 项目要解决的问题

这个项目要解决的不是“单次运行 DSSAT”，而是“自动校准作物品种遗传参数”。

更具体地说，它做的是：

1. 从 DSSAT 的 `.CUL` 品种库中找到目标品种
2. 按给定范围随机生成多组遗传参数
3. 批量运行 DSSAT，粗筛表现更好的参数组合
4. 自动生成 PEST 所需的模板、参数、指令、控制文件
5. 让 PEST 从多个较优初值出发做进一步估计
6. 把最优品种系数写回结果文件

所以这个项目本质上是一个“R 编排层 + DSSAT 模拟层 + PEST 校准层”的三段式系统。

## 2. 整体架构

### 2.1 控制层

主控脚本是 [DSSAT_PEST.r](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L2-L603)。

它负责：

- 读取配置
- 准备 DSSAT 工作目录
- 从 `.CUL` 中抽取目标品种参数
- 生成随机参数
- 驱动 DSSAT 批量试跑
- 计算适应度
- 生成 PEST 文件
- 触发 PEST 校准
- 汇总结果

### 2.2 配置层

三个 CSV 决定脚本行为：

- [SimulationControl.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/SimulationControl.csv#L1-L7)：DSSAT 路径、筛选比例、随机样本数、迭代次数、CV
- [CropCultivar.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/CropCultivar.csv#L1-L31)：选择作物类型、基因型文件、目标品种
- [ParameterOutput.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/ParameterOutput.csv#L1-L245)：参数边界、启用标志、PEST 标记、目标输出、观测权重分组

### 2.3 模拟层

DSSAT 相关运行文件集中在 [DSSAT_Files](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_Files)：

- `DSSBatch.v46`
- `Evaluate.OUT`
- `Summary.OUT`
- `PlantGro.OUT`
- 其他 `.OUT` 文件

这个目录相当于脚本临时组装出来的“模拟工作区”。

### 2.4 校准层

PEST 相关文件集中在 [PEST_Files](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_Files)：

- `*.tpl`：模板文件
- `*.par`：参数初值文件
- `*.pmt`：参数名列表
- `*.ins`：输出提取规则
- `nash.pst`：PEST 控制文件
- `*.bat`：调用 PEST/DSSAT 的批处理脚本

### 2.5 外部依赖层

- DSSAT 安装目录由 [SimulationControl.csv](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/SimulationControl.csv#L2-L7) 提供
- PEST 可执行文件目录固定为项目下的 [PEST_software](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/PEST_software)

## 4. 这个项目的核心思想

项目最重要的设计不是某个语法细节，而是“两阶段搜索”：

### 第一阶段：随机粗筛

脚本先在参数边界内随机生成很多组候选值，然后直接调用 DSSAT 试跑，利用输出与观测的匹配程度计算适应度，只保留前若干比例的较优候选。

对应代码：

- 生成随机参数：[DSSAT_PEST.r:L93-L103](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L93-L103)
- 逐个运行 DSSAT：[DSSAT_PEST.r:L157-L193](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L157-L193)
- 按适应度排序：[DSSAT_PEST.r:L196-L209](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L196-L209)

### 第二阶段：PEST 精调

在较优初值附近，再利用 PEST 的参数估计能力进一步搜索更优结果。

对应代码：

- 生成 `tpl/par/ins/pst`：[DSSAT_PEST.r:L215-L358](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L215-L358)
- 多初值循环调用 PEST：[DSSAT_PEST.r:L494-L570](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r#L494-L570)

如果把这个仓库当成一个软件系统来看，它并不是通用 R 包，也不是模块化应用，而是一个以 [DSSAT_PEST.r](file:///d:/Wheat/Wheat/docs/reference/DSSAT-PEST/DSSAT_PEST.r) 为中心、面向 DSSAT 品种参数校准任务的自动化脚本工程。
