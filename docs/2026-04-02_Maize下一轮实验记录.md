## 6. 下一轮研究重点与实施计划

### 6.1 总体结论

下一轮研究重点应明确收敛到 **“MGDA 主探索 + O1 局部精修”** 的有效率定框架，而不是继续把主要资源投到 O2 上。

同时，评价标准不能再只以 Maize 单作物为依据，而应扩展为 **5 种作物的综合评价框架**，以跨作物平均得分、方差与排序稳定性作为主判断标准。

如果目标同时是“做出更有效的工程率定流程”与“形成论文可讲清的研究故事”，最优主线应为：

- **主线**：把 `O5(MGDA) -> O1` 做成稳定、可复验、可解释的主流程
- **辅线**：把 O2 保留为“阈值/失稳机理诊断工具”
- **对照线**：保留 O4/NSGA-II 作为方法学对照，但不再做重投入
- **评价线**：将单作物结论升级为 5 作物综合指标，避免只在 Maize 上成立的局部最优叙事

### 6.2 为什么研究方向要转向这一主线

- 目前最强结果已经不在 O2，而在 MGDA 这条线上：`lhs_3` 是当前最佳有效起点，MGDA 多起点信息也更丰富 [2026-04-02_Maize下一轮实验记录.md:L117-L120](file:///c:/DSSAT48/Wheat/docs/2026-04-02_Maize下一轮实验记录.md#L117-L120)
- 更关键的是，混合框架已经被正向验证：`lhs_3 -> O1` 把 score 从 `0.430738` 进一步压到 `0.421949`，明显优于 O1 直接盲搜 [2026-04-02_Maize下一轮实验记录.md:L106-L113](file:///c:/DSSAT48/Wheat/docs/2026-04-02_Maize下一轮实验记录.md#L106-L113)
- O2 当前的核心价值主要是“告诉我们哪里会失稳”，而不是“提供最优解”：`48/16/3` 没带来质量提升，`56/20/3` 出现 conflict 跳变，`72/24/4` 已进入明显停滞区 [2026-04-02_Maize下一轮实验记录.md:L82-L96](file:///c:/DSSAT48/Wheat/docs/2026-04-02_Maize下一轮实验记录.md#L82-L96)
- 但仅凭 Maize 单作物还不足以支撑“有效率定框架”的论文结论，必须进一步检验该框架在 5 种作物上的 **平均表现、波动水平与跨作物一致性**

### 6.3 下一轮研究主问题

建议把论文核心问题收敛成一句话：

**在 5 种作物的多目标率定任务中，是否可以通过“Pareto 前沿探索 + 单目标局部精修”构建一个兼具精度、稳定性与可解释性的有效率定框架？**

这个问题有三个直接优点：

- 和当前最佳结果直接一致
- 能把方法、机制与工程可用性连成一个完整研究链条
- 容易形成论文结构：问题背景 → 框架设计 → 跨作物对照实验 → 机制解释 → 工程建议

### 6.4 下一轮优先级

#### 优先级 1：固化 `MGDA -> O1` 主流程

- 这是最值得投入的方向
- 目标不是再刷一次最低分，而是证明这条流程 **稳定可复验**
- 需要回答的问题是：不同 seed / 不同起点下，MGDA 是否稳定找到好盆地？O1 接手后是否稳定进一步下降？这种趋势在 5 种作物上是否同时成立？

#### 优先级 2：把 MGDA archive 变成“论文级代表解”

- 不再只报一个 best point
- 从 archive 中固定形成 3 类代表方案：`综合折中`、`产量优先`、`冠层/生物量优先`
- 将这些代表解映射到“参数结构 -> 误差结构 -> 农艺解释”的链条上

#### 优先级 3：把 O2 定位成诊断工具，而不是主率定器

- O2 的价值在于证明 IES 存在清晰的阈值行为与失稳边界
- 这部分对论文很重要，因为它解释了“为什么某些常见框架在该问题上不适合作为主工作流”

#### 优先级 4：保留 O4 作为轻量对照

- 只需要足够支撑“MGDA 的优势不是偶然命中”
- 不值得再做大规模深挖

#### 优先级 5：建立 5 作物综合评价体系

- 不再以单作物最佳结果作为唯一标准
- 对每种方法在 5 种作物上统一统计综合 score、平均值、标准差、方差和排名
- 明确区分“单作物极优”和“跨作物稳健最优”

### 6.5 具体研究重点

#### 重点 A：框架有效性

- 比较 `O1 direct`、`O5 direct`、`O5 -> O1`
- 核心考察三件事：最终 score、复现稳定性、对初始化的敏感性
- 评价粒度从单作物扩展到 5 作物联合统计，至少输出平均 score、score 方差和跨作物排名一致性
- 这部分决定“是否能称为有效率定框架”

#### 重点 B：框架可解释性

- 对 MGDA archive 代表解进行物候、冠层、生物量、产量四类目标拆解

### 6.6 不建议再重投的方向

不建议下一轮继续把主要资源投入“大范围 O2 网格搜索”。

原因很直接：

- 它已经暴露了关键阈值信息
- 但没有显示出比 MGDA 更强的率定能力
- 继续扩大投入的边际论文收益不高

因此，O2 最多保留为三类用途：

- 阈值证据补点
- 失稳机理日志分析
- 对主结论的反证材料

### 6.7 论文叙事建议

论文主叙事不建议写成“我们试了很多优化器，MGDA 恰好最好”，更好的写法是：

**单一优化框架在多作物率定问题上存在结构性局限；多目标前沿探索能更稳定地发现可行盆地，而单目标局部精修能够进一步提升综合精度，因此二者耦合形成更有效、也更可解释的率定框架。Maize 用于展示失稳机制与参数解释，5 作物综合统计用于支撑主结论。**

这条叙事可拆分为四层：

- **问题层**：传统框架不稳定，尤其 O2 存在阈值失稳
- **方法层**：MGDA 保留 Pareto 结构，提供更好的探索能力
- **工程层**：O1 局部精修把可行盆地转化为更低综合误差
- **研究层**：不仅得到更好分数，也得到跨作物稳健性证据、机制解释与代表解分析

| `O5 direct` | `0.293093` | `2` | 当前平均分最低，说明 MGDA 的跨作物探索价值最稳定 |
| `O5 -> O1` | `0.339669` | `2` | 在 Maize / Rice 上形成明确增益，在 Wheat / Cotton 上未超过最佳 direct 方法 |

据此，当前最稳妥的论文级表述应更新为：

- **主结论 1：`MGDA` 已经是当前 5 作物上最稳的第一阶段探索器。** 从平均 score 看，`O5 direct` 目前最低
- **主结论 2：`O5 -> O1` 的价值是“把一部分作物的好盆地继续推低”，而不是替代 `O5` 成为所有作物上的统一最优终点**
- **主结论 3：如果论文要强调“有效率定框架”，最佳表述应是“两阶段框架优于 direct O1，且提供了比单纯局部法更稳的跨作物可执行性”；如果要强调“当前最低平均误差”，则主结果暂时更偏向 `O5 direct`**

因此，下一轮最值得做的已不再是盲目继续补单个作物，而是把这 5 作物结果统一整理成平均值、方差、最优次数与排名波动表，正式进入论文主表阶段。

### 7.15 5 作物统计量与排名稳定性

为了把当前判断从“现象描述”升级到“论文主表口径”，本轮进一步把 `O1 direct`、`O5 direct`、`O5 -> O1` 做了统一统计。

这里采用的是：

- `final score` 的 **5 作物总体平均值**
- **总体标准差** 与 **总体方差**
- 按每个作物内 `final score` 从低到高得到的方法排名
- **平均名次** 与 **作物内最优次数（含并列）**

统计结果如下：

|---|---:|---:|---:|---:|---:|

这张表给出了一个比单看平均值更细的结论：

- **如果看平均 score，当前最强方法是 `O5 direct`。** 它在 5 作物上的平均误差最低
- **如果看排名稳定性，当前最稳的方法反而是 `O5 -> O1`。** 它虽然平均分略高于 `O5 direct`，但平均名次最低，说明更少出现“特别差的一作物”
- **如果看波动，`O5 -> O1` 的方差最低。** 这说明两阶段框架在跨作物层面更平滑，极端失配程度更小

- **精度主表述**：若强调“最低平均误差”，当前应由 `O5 direct` 代表主结果
- **稳健性主表述**：若强调“跨作物稳定率定框架”，当前应由 `O5 -> O1` 代表主结果

这两条表述并不矛盾，反而很适合形成论文中的“双层结论”：

- `MGDA` 提供更强的第一阶段探索能力，因此把平均误差拉低
- `O1` 热启动接管后，不一定总能把平均值继续压到最低，但能降低跨作物波动、改善平均排名

从论文叙事角度，这意味着主结论可以进一步收敛成一句更稳的话：

**`O5(MGDA)` 是当前跨作物平均精度最优的探索器，而 `O5 -> O1` 是当前跨作物排名最稳、方差最小的两阶段率定框架。**

### 7.17 当前比较框架与权重方案梳理

为了避免后面写论文时口径漂移，这里把“当前到底在比什么、怎么加权”一次说清楚。

#### 7.17.1 当前比较的优化器

| 记号 | 实际优化器 | 当前角色 |
|---|---|---|
| `O1` | `o1_least_squares` | 标量局部法 direct baseline |
| `O2` | `o2_pestpp_ies` | `PEST-IES` 扩展对照 |
| `O4` | `o4_nsga2` | `NSGA-II` 轻量方法学对照 |
| `O5` | `o5_mgda` | `MGDA` 多目标第一阶段探索器 |
| `O5 -> O1` | `o5_mgda` 后接 `o1_least_squares` | 两阶段混合框架 |

因此，**现在的对比方式里是包含 `PEST-IES` 的**，只是它当前以 `O2` 的形式存在，而且完整 5 作物覆盖主要来自 `quick` 预算层。

#### 7.17.2 当前统一 benchmark 设置

当前批量对照矩阵在运行时统一固定为：

- `weight = w8_dssat_group_max`
- `sequence = s2_sequential_phase`
- `grouping = g3_dssat_extended`
- `boundary layer = current_project_revised`

这意味着当前所有主线结果，不是“每个作物各用一套完全不同规则”，而是在同一套加权、同一套阶段式率定顺序下完成的。

#### 7.17.3 当前权重方案 `w8_dssat_group_max`

`w8_dssat_group_max` 不是简单的“每个指标等权”，而是 **先分组，再按观测量级做组级缩放**。

当前分组方式采用 `g3_dssat_extended`：

- `phenology_time`：`ADAP`、`MDAP`
- `canopy_state`：`LAIX`
- `biomass_total`：`CWAM`
- `yield_total`：`HWAM`
- `yield_unit_weight`：`HWUM`

如果某个作物没有某个指标，该组就自动跳过，不强行补零。

组权重的计算方式是：

- 对每个组，取训练集观测值绝对值的最大值 `group_max`
- 该组基础权重设为 `1 / group_max`
- 然后再对所有组权重做一次均值归一，使“平均组权重 = 1”
- 同一组内的各指标继承同一个组权重

这套设计的实际含义是：

- **量纲大的指标不会天然主导损失函数**
- **同一类生理过程内的指标保持同组权重**
- **不同作物即使观测量级差异很大，也能放到同一 benchmark 口径下比较**

#### 7.17.4 当前阶段式率定顺序 `s2_sequential_phase`

当前不是把所有参数和所有指标一次性扔给优化器，而是按阶段推进：

- **Phenology 阶段**：优先对 `ADAP / MDAP` 相关参数率定
- **Biomass 阶段**：再处理 `LAIX / CWAM`
- **Yield 阶段**：最后处理 `HWAM / HWUM`

这相当于把“时间过程 → 冠层/生物量 → 产量结果”拆开，避免单阶段 joint 优化把不同生理层级揉成一个难以解释的大黑箱。

#### 7.17.5 `PEST-IES` 在当前框架中的位置

`PEST-IES` 对应的是 `O2`，当前已经接入统一框架，而且运行时也继承同样的：

- 指标权重模式 `w8_dssat_group_max`
- 阶段顺序 `s2_sequential_phase`
- 分组定义 `g3_dssat_extended`

但它和 `O1 / O5` 还有一个实现差异：

- 在 `s2_sequential_phase` 下，`O2 / PEST-IES` 的 `phenology` 与 `biomass` 阶段会把 `yield_partition_stage` 的参数一并纳入活动参数集

这意味着当前 `PEST-IES` 不是一个“完全孤立每一阶段参数块”的版本，而是一个 **带部分参数联动的阶段式 IES**。因此它适合作为扩展基线，但若后面要做非常严格的“优化器同层公平对比”，还可以再补一轮完整 `phase3_formal` 的 `O2`。

综上，当前比较框架应当这样表述：

- **主线结论层**：`O1 direct` vs `O5 direct` vs `O5 -> O1`
- **扩展优化器层**：补充 `O2 / PEST-IES` 与 `O4 / NSGA-II`
- **统一权重口径**：`w8_dssat_group_max + s2_sequential_phase + g3_dssat_extended`
